정액제의 종말 — GitHub Copilot, 토큰/크레딧 과금으로 전환

Claude Code v2.1.166 — fallback 모델·deny 규칙 글롭 추가

6월 6일자 changelog 기준, 기본 모델이 과부하·불가일 때 순서대로 시도할 fallback 모델을 최대 3개까지 지정하는 fallbackModel 설정 추가. --fallback-model이 인터랙티브 세션에도 적용됨. deny 규칙의 도구명 자리에 글롭(*) 지원 — '*'로 모든 도구 차단 가능. 장시간 세션 안정성과 권한 통제가 동시에 촘촘해짐.

Windsurf, 'Devin Desktop'로 통합 — ACP 표준 채택

6월 2일 Cognition이 Windsurf 브랜드를 접고 Devin Desktop으로 재출시. Cascade 후속인 Devin Local은 Rust로 재작성돼 토큰 효율 최대 30% 개선·서브에이전트 지원. 모든 로컬·클라우드 에이전트를 한 칸반 보드(Agent Command Center)에서 관리하고, 개방형 Agent Client Protocol(ACP)을 기본 지원. 에이전트가 에디터에 종속되지 않는 '상호운용' 흐름이 빨라짐.

Anthropic+MITRE, AI 사이버 위협 1년 매핑 — 거버넌스 강화

6월 3일 Anthropic이 1년간(2025.3~2026.3) 차단한 악성 계정 832건을 MITRE ATT&CK에 매핑한 보고서 공개. 67.3%가 악성코드 작성 등 공격 준비에 AI를 썼고, AI 활용이 초기 침투에서 침투 후(lateral movement) 단계로 이동 중. 같은 주(6/2) Project Glasswing을 15개국 ~150개 기관으로 확대. 에이전트 오케스트레이션을 위협 범주로 다루는 흐름 — Claude Code의 권한·샌드박스 가드레일도 함께 단단해지는 배경.
