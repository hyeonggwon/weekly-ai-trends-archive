Claude Opus 5.5 출시, Claude Code 새 기본 모델로

Anthropic이 9월 22일 Claude Opus 5.5를 공개함. Opus 5와 동급 성능을 유지하면서 비용은 40% 낮췄고(입력 $4/M, 출력 $20/M, 캐시 읽기 $0.20/M), 에이전틱 코딩 벤치마크에서 선두를 유지함. Claude Code에서 곧바로 기본 모델로 전환됨 — 같은 예산으로 더 긴 세션·더 많은 에이전트 실행이 가능해짐.

GitHub Copilot, 멀티모델 라인업 확장 — Opus 5.5·GPT-6·Grok 4.7 동시 탑재

GitHub Copilot이 9월 21일 주간 릴리스에서 Claude Opus 5.5, GPT-6 Sol, GPT-6 Luna, Grok 4.7을 플랜별로 추가함. VS Code 1.139는 SSH·Tunnel·WSL Dev Container 안에서 에이전트 실행을 지원함. 특정 모델에 종속되지 않는 '멀티모델 기본값' 전략이 코딩 에이전트 시장 전반으로 퍼지고 있어, Claude Code 사용자도 경쟁 제품의 모델 선택권을 벤치마크 기준으로 삼기 좋아짐.

코딩 에이전트, 이번 주 일제히 '보안·거버넌스' 기능 강화

Cursor는 9월 23일 배포 상태를 추적하는 Rollouts와 PR 취약점을 자동 탐지하는 Security Review를 출시함. GitHub Copilot 앱은 파일·네트워크·자격증명 접근을 제한하는 로컬 샌드박싱을 프리뷰로 내놓음. Claude Code도 같은 주 데스크톱 보안 통제·AWS 크로스어카운트 접근 개선과, 관리자가 특정 모델 버전을 고정·차단하는 설정(availableModelsMatch, deniedModels)을 추가함. Claude Code 팀 사용자는 이번 주부터 어떤 모델·권한을 조직 단위로 허용할지 더 세밀하게 통제할 수 있음.
