Claude Code에 `--restricted` 등장, 한 주 내내 권한 경계 조이기

v2.1.248이 `--restricted`(또는 `CLAUDE_CODE_RESTRICTED=1`)를 추가함. 명령·코드 실행 도구와 WebFetch를 제거하고, 파일 도구를 작업 디렉터리 안에 가두며, bypassPermissions를 거부하고 user/project/local 설정 파일을 아예 무시함. 이어서 v2.1.251은 심링크 스왑으로 승인 범위 밖 파일을 읽고 쓰던 문제, 플러그인 커맨드의 경로 탈출, Grep/Glob이 심링크 경로에 Read 거부 규칙을 적용하지 않던 문제를 한꺼번에 고침. 샌드박스 TLS 종료·프록시 주입·`ANTHROPIC_CUSTOM_HEADERS` 같은 관리 설정은 이제 적용 전 승인이 필요함.

Anthropic, Model Hardware Standard(MHS) 리서치 프리뷰 공개

8월 27일 Anthropic이 AI 에이전트가 물리 장비를 안전하게 조작하기 위한 공유 규격 MHS를 과학 연구소·첨단 제조 기업 일부에 먼저 열었음. 프로그래밍 인터페이스가 있는 장비라면 무엇이든 붙고, 모델에 종속되지 않으며 MCP 같은 표준 프로토콜로 접근함. 초기 테스트에서 Genentech 신약 탐색 실험 실시간 오류 처리, HHMI Janelia 이미징 실험 수 주 → 하루 단축, QuEra 양자컴퓨터 레이저 안정화 58% → 99.3% 개선 사례가 나옴. 같은 날 과학자 대상 Claude 팀 플랜 1만 석(스탠다드 무료, 프리미엄 월 $15)도 함께 발표.

세션 간 메시징이 전 프로바이더로 확대, 에이전트 팀 실사용 버그 정리

프롬프트 캐시와 지출이 드디어 눈에 보이기 시작함

`experimental.cacheTtl`로 에이전트별 캐시 TTL을 잡고, `promptCacheTtl`·`subagentPromptCacheTtl`로 메인 대화는 1시간·서브에이전트는 5분처럼 나눠 쓸 수 있게 됨. `/cost`에 세션별 캐시 적중률·재캐시 토큰 라인이, `/usage`에 Spend limit 바와 Loops 브레이크다운이 추가됨. OAuth 토큰 갱신 후 도구 정의가 다시 렌더링되며 긴 세션에서 시간당 한 번씩 캐시가 깨지던 버그도 수정. `modelPricing` 관리 설정으로 조직 계약 단가가 비용 표시에 반영됨.

경쟁 진영도 '끝나지 않는 에이전트'로 — OpenAI Codex Persistent mode 정황

8월 27일 Wired가 OpenAI Codex CLI 코드베이스에서 'Persistent mode' 흔적을 포착함. 명시적으로 재우기 전까지 계속 돌면서 세션을 넘어 스스로 후속 작업을 만드는 상시 가동 에이전트 구상. OpenAI 측은 테스트 중이라고 확인했으나 출시 계획은 없다고 선을 그었으므로 [루머] 취급이 맞음. 같은 주 Google Cloud는 법률 산업 특화 에이전트 Gemini Enterprise for Legal을 프리뷰로 내놓음(Cleary·Freshfields·Weil·Williams & Connolly). 상시 가동과 수직 특화, 두 방향이 동시에 밀리는 중.
