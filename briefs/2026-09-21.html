서브에이전트 결과에 '신뢰 경계' 도입 — 프롬프트 인젝션 방어 강화

Claude Code 2.1.277에서 서브에이전트의 결과가 메인 에이전트에 전달될 때 '서브에이전트 출력'이라는 헤더로 구분되고 들여쓰기되어, 서브에이전트 결과 안의 텍스트가 세션 자체의 지시로 오인되지 않도록 바뀜. 워크플로우 스크립트가 만든 프롬프트도 '스크립트가 작성한 텍스트'로 표시되어 안전 분류기가 사용자 발화로 착각하지 않게 함. 여러 에이전트를 조합해 쓰는 사용자에게는 프롬프트 인젝션 공격 표면이 줄어드는 실질적 방어 강화.

AGENTS.md 지원 추가, 그런데 원격 게이트 뒤에 숨어있었다

Claude Code 2.1.277부터 CLAUDE.md가 없는 프로젝트에서 AGENTS.md를 대신 읽는 기능이 추가됨. 문제는 이 기능이 Anthropic 서버의 원격 feature flag(Statsig gate)로 켜고 끄는 구조라는 점 — 텔레메트리를 끄거나(CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1) Bedrock/Vertex/서드파티 게이트웨이로 쓰는 사용자는 이 게이트가 평가될 수 없어 로컬 파일 하나 읽는 기능이 조용히 비활성 상태로 남는다는 이슈가 GitHub와 Hacker News에서 제기됨. 로컬 전용 기능이 네트워크 의존적으로 설계된 데 대한 비판.

Auto mode 분류기 과금 방식 개편 — 서버사이드가 기본값으로

2.1.278에서 Claude API·Enterprise 사용자, 그리고 Bedrock/Vertex/Foundry/게이트웨이 환경에서 auto mode의 모델 분류 작업이 서버사이드 분류기로 기본 전환됨. 분류기 실행 자체에 별도 과금이 붙지 않게 되어, auto mode를 상시 켜두는 사용자의 숨은 비용 부담이 줄어듦. /status에 분류기가 서버에서 도는지 보여주는 행이 추가돼 확인도 쉬워짐.

Cowork·Chat 통합, Projects는 '폴더'에서 '대화'로 재설계

Anthropic이 Claude Cowork와 일반 채팅을 하나의 Claude 경험으로 합치고(9/16), 곧이어 Projects를 파일 폴더 개념에서 대화 중심 구조로 다시 설계함(9/17). 여러 제품 표면이 쪼개져 있던 걸 하나로 모으는 방향으로, Claude Code 사용자도 브라우저·클라우드 세션·프로젝트 맥락이 점점 하나의 워크스페이스로 수렴하는 흐름을 체감하게 됨.
