Claude Code, Opus 5 기본 채택 + 중첩 서브에이전트 depth 3

v2.1.220(7/24)에서 Opus 5를 기본 Opus 모델로 채택. /code-review는 백그라운드 서브에이전트로 돌아 대화창을 채우지 않음. 서브에이전트가 최대 depth 3까지 중첩 서브에이전트를 생성(기존 1). 긴 세션 메모리 누수와 초장문 단일 라인 파일 읽기 시 메모리 급증 문제도 수정됨. 의미: 복잡한 멀티스텝 작업을 서브에이전트 트리로 위임하기 쉬워지고, 리뷰가 대화 흐름을 방해하지 않음.
