Anthropic, Fable 5·Mythos 5 공개 — Mythos급 모델을 일반에 처음 풀다

6월 9일 Anthropic이 Fable 5를 출시함. Opus 상위 티어인 Mythos급 모델에 안전장치를 얹어 일반 공개한 첫 사례. 소프트웨어 엔지니어링·지식노동·비전·과학연구에서 거의 모든 벤치마크 SOTA. Stripe는 5천만 줄 Ruby 코드베이스 전체 마이그레이션을 하루 만에(수작업 두 달치) 끝냈다고 보고. 가격은 $10/$50 per Mtok, Pro·Max·Team에 6/9~6/22 한시 무료 포함. Claude Code 입장에선 사상 가장 강력한 코딩 모델이 잠깐 손에 들어온 셈.

사흘 만에 차단 — 미국 정부 수출통제로 Fable 5·Mythos 5 전면 비활성화

출시 사흘 뒤인 6월 12일, 미국 정부가 국가안보를 근거로 두 모델에 수출통제 지시를 발령함. 외국 국적자(미국 내·외 불문, Anthropic 외국적 직원 포함) 전원 접근 금지. Anthropic은 컴플라이언스를 위해 모든 고객 대상으로 Fable 5·Mythos 5를 껐음. 우려의 핵심은 사이버보안(소프트웨어 취약점 탐색) 안전장치 우회 가능성. Opus 4.8 등 나머지 모델은 정상 유지. Claude Code 입장에선 2.1.170으로 막 붙인 Fable 5가 다시 사라진 것 — 프런티어 역량이 수출통제와 직결되는 국면.

Claude Code, Fable 5 당일 통합 + 모델 거버넌스 강화

Claude Code는 2.1.170(6/9)에서 Fable 5를 출시 당일 지원함. 이후 며칠간 1M 컨텍스트 기본 적용, 사용량 크레딧 배너, Fable 차단 시 Opus로 자동 폴백, 그리고 조직이 허용 모델을 강제하는 enforceAvailableModels 관리형 설정까지 연달아 출시(2.1.172~176, 6/10~12). 세션 제목을 대화 언어로 생성하는 변경도 포함. 새 모델이 떠도 같은 날 쓸 수 있고, 엔터프라이즈는 어떤 모델을 쓰는지 통제할 수 있다는 의미.

서브에이전트가 서브에이전트를 — 5단계 깊이 오케스트레이션

2.1.172(6/10)에서 서브에이전트가 자기 서브에이전트를 다시 스폰할 수 있게 됨(최대 5단계 깊이). 마켓플레이스 플러그인 검색바, 긴 대화 렌더링 성능 개선, Claude in Chrome 툴 배치 로딩도 같이 들어옴. 복잡한 작업을 트리 구조로 쉽게 분해해 병렬로 돌리기가 한층 수월해졌다는 뜻 — 에이전트 오케스트레이션의 계층이 깊어지는 흐름.
