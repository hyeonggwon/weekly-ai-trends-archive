OpenAI도, Anthropic도 더 이상 한 클라우드에 묶이지 않는다

Claude가 Blender·Adobe·Autodesk·Ableton까지 — MCP 커넥터 9종 동시 공개

4월 28일 Anthropic은 크리에이티브 워크플로우용 공식 MCP 커넥터 9종(Blender, Adobe, Autodesk, Ableton, Splice, Affinity, SketchUp 등)과 신규 제품 Claude Design을 공개. 핵심은 "Claude Code에서 쓰던 MCP 패턴 그대로" 3D·디자인·오디오 도구로 확장된다는 점. 같은 플러그인/스킬 인프라가 코드 밖 도메인으로 검증되는 중. Claude Code 유저는 MCP 커넥터 작성 노하우를 그대로 다른 도메인 자동화에 옮길 수 있다.

Claude Code 2.1.118→2.1.126: 6일 만에 9개 패치, 잔잔한 디테일 정리 주간

이번 주 changelog는 신규 플래그십 기능 대신 "누가 쓰면 진짜 빡쳐 있을" 자잘한 버그 수렴이 핵심. 2.1.121에서 plugin prune 추가(고아 의존성 자동 정리), 2.1.120에서 /ultrareview 비대화형 실행, Windows에서 Git for Windows 없이 PowerShell 폴백, OAuth 토큰 리프레시 경합 처리 개선. 그리고 5월 1일 2.1.126으로 SSH/WSL/컨테이너에서 OAuth 콜백을 받지 못할 때 코드 페이스트 폴백, Mac 슬립 후 "Stream idle timeout" 복구, claude project purge, 매니지드 세팅 샌드박스 보안 픽스가 한 번에 들어왔다. 업그레이드해서 손해 볼 게 없는 주.
