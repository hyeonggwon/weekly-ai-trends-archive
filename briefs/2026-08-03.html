MCP 2026-07-28 스펙 공개 — 프로토콜이 stateless 코어로 전환

MCP 다섯 번째 스펙이 나오면서 양방향 stateful → 요청/응답 stateless 구조로 바뀜. 세션·핸드셰이크(initialize/Mcp-Session-Id) 제거, Mcp-Method 헤더 기반 라우팅, tools/list 결과 캐싱, OAuth 2.0·OIDC 정합(RFC 9207)까지. Claude Code 사용자에겐 remote MCP 서버가 serverless·edge에서 세션 관리 없이 돌아가 커넥터가 더 안정·확장되고, Entra·Okta 같은 엔터프라이즈 인증에 그대로 붙는다는 뜻.

Opus 5, 주요 코딩 에이전트의 기본 모델로 안착

7월 24일 공개된 Opus 5가 이번 주 Cursor·Devin·Kiro·JetBrains 등으로 확산되며 Claude Code의 기본 모델로 자리잡음. 가격은 Opus 4.8과 동일($5/$25, 1M 토큰), Frontier-Bench·CursorBench에서 Fable 5에 근접하되 절반 비용. 안전 분류기에 걸리는 요청은 기본적으로 Opus 4.8로 자동 폴백. Claude Code 사용자는 별도 설정 없이 최신 성능을 쓰되, cyber 관련 일부 작업엔 가드레일이 더 붙었다는 점을 알아두면 됨.
