Claude Opus 4.8 공개 — Effort Control과 더 싸진 Fast Mode

Anthropic이 5월 28일 Opus 4.8을 출시. 에이전트 코딩 64.3%→69.2%, 멀티스텝 추론 54.7%→57.9%로 향상되고, 응답 효성(effort)을 사용자가 조절하는 기능이 claude.ai에 추가됨. Fast mode는 2.5배 속도에 이전 대비 3배 저렴해졌고 가격은 Opus 4.7과 동일($5/$25). Claude Code 사용자에게는 같은 가격에 더 정확하고, 길게 일하는 모델이 기본값으로 들어온다는 뜻.

Dynamic Workflows — Claude Code가 1000개 subagent를 직접 조립한다

같은 날 공개된 Dynamic Workflows는 사용자가 작업을 설명하면 Claude가 JavaScript 오케스트레이션 스크립트를 직접 작성, 백그라운드 런타임이 최대 동시 16개·총 1000개까지 subagent를 병렬 실행. 다른 에이전트가 결과를 반박·검증한 뒤 묶어서 돌려줌. 'planning에서 execution까지'를 한 세션 안에서 끝내는 구조로, 리서치 프리뷰 단계지만 모든 유료 플랜과 Bedrock·Vertex·Foundry에서 바로 켤 수 있음.

.claude/skills의 플러그인이 마켓플레이스 없이 자동 로드됨

5월 29일자 Claude Code v2.1.157에서 .claude/skills 디렉터리에 둔 플러그인이 별도 마켓플레이스 등록 없이 자동 인식. 새로 추가된 claude plugin init <name>이 스캐폴드를 만들어주고, /plugin 인자에 서브커맨드·설치된 플러그인·마켓플레이스 후보까지 자동완성. 다음 날(v2.1.158)에는 Bedrock·Vertex·Foundry에서도 Opus 4.7/4.8에 대해 Auto Mode가 풀림. 개인 워크플로우를 그대로 팀 레포에 커밋해 공유하는 흐름이 표준화됨.

Mythos급 보안·코딩 모델 일반 배포 임박 — 'coming weeks' 공식화

Series H 공지와 함께 Anthropic이 Mythos-class 모델을 일반 고객에게 'coming weeks' 안에 풀겠다고 명시. Mythos는 오픈소스 코드베이스에서 제로데이를 찾아 익스플로잇을 체이닝할 수 있는 수준의 보안·공격 코딩 능력을 가진 모델로, 4월에 Project Glasswing(40+ 인프라 조직)에만 제한 공개됐던 시리즈의 후속. Claude Code 사용자 입장에선 'security-guidance' 류 플러그인이 곧 1급 기능이 될 가능성이 큼.
