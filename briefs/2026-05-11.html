Code with Claude 2026 — 새 모델 없이, Managed Agents에 'Dreaming·Outcomes·Multi-agent' 투하

5/6 SF Code with Claude 키노트는 신규 모델 발표 없이 에이전트 인프라에 집중. Claude Managed Agents에 ① Dreaming(세션 사이에 메모리 자기정리·자기개선, research preview), ② Outcomes(성공 기준 루브릭 + 별도 grader로 self-correct), ③ Multi-agent orchestration(lead agent가 서브에이전트에 병렬 위임 + Console에서 trace) 추가. Harvey는 dreaming 적용 후 작업 완료율 6배, Netflix는 multi-agent로 빌드 로그 분석 병렬화. API 사용량은 전년 대비 17배 성장 공개.

OpenAI, GPT-5.5 Instant를 ChatGPT 기본 모델로 — 환각 -52.5%, Realtime 음성 3종 동시 공개

5/5 OpenAI가 GPT-5.5 Instant를 ChatGPT 기본 모델(API도 chat-latest)로 롤아웃. 5.3 Instant 대비 고위험 영역(의료·법률·금융) 환각 주장 52.5% 감소, 까다로운 대화에서 부정확 주장 37.3% 감소. Plus/Pro는 과거 대화·파일·Gmail을 더 적극적으로 컨텍스트로 활용. 같은 주 Realtime API에 GPT-Realtime-2(추론)·Realtime-Translate(실시간 다국어)·Realtime-Whisper(스트리밍 STT) 동시 추가. 코딩 에이전트 측에선 'default 모델 자동 갱신'이 다시 한 번 변수.
