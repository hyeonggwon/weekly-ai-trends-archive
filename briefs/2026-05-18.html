Claude Code Agent View — 멀티 에이전트 세션을 한 화면에서 관리

v2.1.139부터 도입된 'agent view'가 이번 주 공개 블로그와 공식 문서로 정식 안내됨. `claude agents`로 켜면 현재 머신의 모든 Claude Code 세션이 한 리스트에 뜨고, 어떤 게 작업 중인지, 어떤 게 사용자 입력 대기인지, 어떤 게 끝났는지 한 눈에 파악·인라인 답변 가능. /bg로 백그라운드에 보낸 작업과 자연스럽게 연결되어 '여러 작업을 동시에 굴리는' 워크플로우가 처음으로 일등시민이 됨.

Fast mode 디폴트가 Opus 4.7로 — 플러그인 SKILL.md를 스킬로 인식

v2.1.142 릴리스에서 Claude Code의 fast mode가 Opus 4.6 → Opus 4.7로 자동 승격됨(이전 동작 원하면 `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1`). 같은 릴리스에서 플러그인 루트의 `SKILL.md`가 자동으로 스킬로 surfacing되고, `/plugin` 디테일 패널이 플러그인이 제공하는 LSP 서버까지 보여주는 등 플러그인 생태계가 한층 매끈해짐. v2.1.141의 `terminalSequence` 훅 필드, `/feedback` 24h/7d 번들, '여기까지 요약' rewind 옵션도 같이.

Claude for Small Business — Claude가 QuickBooks·HubSpot·Canva 안으로 들어옴

5월 13일 정식 출시. QuickBooks·PayPal·HubSpot·Canva·Docusign·Google Workspace·Microsoft 365에 토글 인스톨로 붙고, 급여·송장·마감처럼 '저녁에 쌓이는 일'을 처리하는 사전 정의 에이전틱 워크플로우 15종 + 스킬 15종이 함께 따라옴. Claude Code 사용자에겐 직접적인 기능 변화는 아니지만, '회사 도구 안의 Claude'가 일반 라인업이 되면서 같은 스킬 표준(SKILL.md)이 SMB 영역까지 확장된다는 신호.

Anthropic × Gates Foundation $200M — 4년간 글로벌 헬스·교육에 AI 투입

Google 'Gemini Intelligence' — Pixel·Galaxy 위에서 Gemini가 OS 레벨로 내려옴
