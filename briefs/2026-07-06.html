Claude Code v2.1.196 — 조직 디폴트 모델·MCP 보안 강화

관리자가 콘솔에서 조직/역할 기본 모델을 지정하면 /model에 'Org default'로 표시됨. 세션에 읽기 쉬운 기본 이름 부여, 채팅 첨부파일을 Cmd/Ctrl-클릭으로 파인더에서 바로 열기 추가. 보안: 레포가 커밋된 settings.json으로 자기승인한 .mcp.json 서버는 더 이상 자동 기동하지 않고, 신뢰되지 않은 워크스페이스는 '⏸ Pending approval'로 표시됨. 팀 거버넌스와 MCP 공급망 안전이 함께 조여졌다.
