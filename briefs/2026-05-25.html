Code with Claude London — MCP 터널 + 자체 호스팅 샌드박스 공개

Anthropic이 London 행사에서 MCP tunnels(리서치 프리뷰)와 self-hosted sandboxes(퍼블릭 베타)를 공개. 에이전트 실행 환경을 고객사 인프라(또는 Cloudflare/Modal/Vercel 등 관리형 프로바이더)에 두고, 오케스트레이션 루프만 Anthropic 측에 남기는 구조. 내부 DB·티켓·지식베이스에 인바운드 방화벽 오픈 없이 에이전트가 도달할 수 있게 됨. Claude Code 사용자에겐 사내망 자산을 노출 없이 도구화할 수 있는 첫 공식 경로.

Gemini 3.5 Flash — Flash가 Terminal-Bench 76.2%로 자사 Pro까지 추월

Google I/O 2026에서 공개된 Gemini 3.5 Flash가 Terminal-Bench 2.1 76.2%, GDPval-AA 1656 Elo, MCP Atlas 83.6%를 기록하며 Gemini 3.1 Pro를 코딩·에이전트 전 영역에서 추월. 출력 토큰 속도 약 4배, 가격은 $1.50/$9 per 1M tokens. 1M 컨텍스트 유지. Pro급 가격대를 쓰지 않고도 코딩 에이전트 1티어 후보가 하나 늘어남 — Claude Opus 4.7과의 가격/속도 비교가 본격화될 주.

Antigravity 2.0 · Cursor Composer 2.5 — 에이전트 오케스트레이션이 IDE 메인 화면으로

Google이 Antigravity 2.0을 독립 데스크탑 앱 + CLI + SDK로 재출시. 여러 에이전트를 병렬 실행하면서 한쪽은 코드, 한쪽은 브랜드 자산을 만드는 식의 멀티 에이전트 워크플로가 기본 UI. 같은 주 Cursor도 Composer 2.5(5/18)와 3.5(5/20)로 병렬 에이전트와 dev-env 도구를 확장. Claude Code의 pinned background 세션과 합쳐 보면, '에이전트가 IDE의 1차 인터페이스가 된다'는 방향이 5/19~20에 한 번에 가시화됨.

Claude Code v2.1.147 — /code-review로 PR 코멘트 자동화, 핀 백그라운드 세션

5/21 v2.1.147에서 /simplify를 /code-review로 개명하고 effort 레벨(e.g. /code-review high) 지정 + --comment로 inline GitHub PR 코멘트 자동 작성 가능. 핀 백그라운드 세션(Ctrl+T)이 idle 상태에서도 유지되고, 메모리 압박 시 비핀 세션이 먼저 정리됨. Auto-updater는 네트워크 실패를 재시도하고 OS 에러 코드까지 노출. 5/22엔 v2.1.147 회귀였던 Bash exit code 127 핫픽스. 실무 도구로서의 일상 안정성 라운드.
